## Мета роботи

Навчитися моделювати незмінні дані за допомогою Records та Sealed Types, розділяти дані й алгоритми, реалізовувати 
вичерпну бізнес-логіку через Switch Expressions та Pattern Matching, а також використовувати Text Blocks.

## Опис проєкту

Проєкт реалізує модель станів замовлення на основі `sealed interface OrderStatus` та незмінних типів `record`:

| Стан | Призначення | Дані |
| --- | --- | --- |
| `Pending` | Замовлення очікує обробки | Без додаткових полів |
| `Paid` | Замовлення оплачене | Ідентифікатор платежу та сума |
| `Shipped` | Замовлення відправлене | Трек-код і дата відправлення |
| `Cancelled` | Замовлення скасоване | Причина скасування |

Клас `OrderProcessor` містить метод `process(OrderStatus status)`, який:

- обробляє всі допустимі стани через `switch expression` з pattern matching **без `default`**;
- повертає багаторядкове повідомлення, сформоване за допомогою Text Blocks;
- викидає `IllegalArgumentException`, якщо передано `null`.

Компактні конструктори `record` перевіряють коректність вхідних даних: обов'язкові текстові значення не можуть бути 
порожніми, сума платежу має бути додатною, дата відправлення - заданою.

## Запуск програми

1. Відкрити папку проєкту в IntelliJ IDEA.
2. Переконатися, що вибрано **JDK 21**, і дочекатися завантаження Maven-залежностей.
3. Відкрити файл `src/main/java/ua/kpi/comsys/dop/Main.java`.
4. Запустити метод `main()` через кнопку **Run**.

Програма демонструє обробку чотирьох станів замовлення: `PENDING`, `PAID`, `SHIPPED`, `CANCELLED`.

## Запуск тестів

У терміналі з кореневої папки проєкту виконати:

```bash
mvn clean test
```

Або в IntelliJ IDEA відкрити `ua.kpi.comsys.dop.OrderProcessorTest.java` і вибрати **Run 'ua.kpi.comsys.dop.OrderProcessorTest'**.

Тести на JUnit 5 перевіряють:

- усі чотири гілки `switch` у `OrderProcessor`;
- відповідність результатів очікуваним повідомленням;
- обробку `null` у методі `process()`;
- валідацію полів у `Paid`, `Shipped` та `Cancelled`.

юніт-тести для основних сценаріїв і некоректних вхідних значень.
